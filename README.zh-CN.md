# LeafVault

一个正在规划的免费开源 Markdown 笔记软件：写起来舒服，笔记留在自己的文件夹，同步服务可以自行部署。

**当前阶段：只有规划文档。尚无应用程序、安装包、同步服务或可用的容器镜像。** 下列功能均为目标。

[English](README.md) · [完整产品计划](docs/PRODUCT_PLAN.zh-CN.md) · [里程碑与验收](docs/ROADMAP.zh-CN.md)

## 我们要做什么

用户选择一个文件夹，就能写笔记、插图片、建立双链、搜索内容。离线时正常工作，需要多设备同步时，可以连接自己部署的服务。

官方客户端与同步服务都采用 **AGPL-3.0-only**，官方软件免费用于个人及商业场景，功能不设付费墙，不需要购买许可证，也不按设备数量收费。软件开源免费与服务器、存储、带宽等基础设施成本分别计算。

## 先做好哪些体验

1. 打开即写：本地使用无需注册。
2. 中文输入顺畅：选词、撤销、粘贴、长文编辑行为稳定。
3. 文件可带走：正文是 `.md`，图片和附件保留普通文件格式。
4. 内容找得到：全文搜索、快捷切换、标签和反向链接。
5. 修改可恢复：明确的保存状态、版本历史、冲突副本和恢复操作。
6. 同步可自建：目标是一个应用容器加持久化目录，部署、升级、备份均有文档。

优先交付 macOS 桌面版，再完成自托管同步及 Windows、Linux 验证。移动端单独立项；完整插件生态、多人实时协作、白板和 AI 不进入首版。
