# Contributing to LeafVault

LeafVault is currently a planning project. There is no app to build or sync service to deploy yet.

Useful contributions at this stage include:

- Describing a real note-taking workflow and its most frustrating steps.
- Improving the product, architecture, sync, or acceptance plans.
- Providing small, synthetic Markdown compatibility cases.
- Reviewing accessibility, Chinese input, migration, and recovery requirements.

Please read the [product plan](docs/PRODUCT_PLAN.zh-CN.md) and [roadmap](docs/ROADMAP.zh-CN.md) before proposing a major change. Keep proposals focused on a concrete user need and explain how success can be checked.

Use an issue or pull request in this repository. Chinese and English are both welcome. Treat other contributors respectfully and discuss the work.

## Planning and implementation

Documents must distinguish proposals from implemented and tested behavior. Do not add installation commands, download links, performance claims, or supported-platform badges for features that have not shipped.

The next implementation work should follow the selected milestone and record decisions, results, and remaining limitations. Large changes to storage or sync need a written account of migration and recovery behavior.

## Examples and diagnostics

Use synthetic notes and test accounts. Do not include personal vaults, attachments, server credentials, or access tokens in public reports. Redact any credential as `[REDACTED_SECRET]`.
